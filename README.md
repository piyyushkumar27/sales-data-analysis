# Sales Data Analysis

Analysis of 2,000 sales orders using **Python (pandas)**, **SQL (SQLite)**, **Excel** and **Power BI**.

![Monthly revenue and revenue by category](charts.png)

## Business question
Which products, categories, cities and months bring in the most revenue, and where should a business focus?

## Dataset
- 2,000 orders from Jan to Dec 2025: 8 products, 4 categories, 6 Indian cities, 4 payment methods
- Columns: order_id, order_date, city, category, product, unit_price, quantity, discount_percent, payment_method, revenue
- **The data is synthetic (made-up) practice data**, generated by `generate_data.py`. It includes a few deliberately messy rows (blank cities and duplicates) to practise cleaning.

## Tools
| Tool | Used for |
|---|---|
| Python (pandas, matplotlib) | Cleaning, analysis, charts |
| SQL (SQLite) | 10 queries answering the same questions |
| Excel | Pivot tables and charts |
| Power BI | Interactive dashboard |
